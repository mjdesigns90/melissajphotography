# Melissa J Photography — Landing Page

A simple, mobile-friendly GitHub Pages landing page for Melissa J Photography.

## Files

- `index.html` — page content and links
- `style.css` — design, layout, colors, animations
- `script.js` — copyright year + temporary Fine Art link
- `images/mjphotography-logo.png` — uploaded MJPhotography logo
- `images/beauty-awaits-logo.png` — uploaded Beauty Awaits logo

## To update the Fine Art Prints section

1. Put your future image in the `images` folder.
2. Rename it to `fine-art-placeholder.jpg` (or update the filename in `index.html`).
3. Find the Fine Art card in `index.html`.
4. Replace `href="#"` with your Fine Art shop URL.
5. Replace the placeholder `<div class="art-placeholder">...</div>` with an `<img>` if desired.

The two existing brand links are already set to:

- https://www.headshotsocala.com
- https://www.beautyawaitsphotography.com

## Publish with GitHub Pages

1. Create a new GitHub repository, e.g. `melissa-j-photography`.
2. Upload all files and the `images` folder.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide your live Pages URL.

You can later connect a custom domain from the same Pages settings.
